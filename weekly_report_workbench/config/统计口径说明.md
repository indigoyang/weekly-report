# 周报统计口径说明

> 本文描述的是程序当前实际执行的口径。修改 `report_rules.json` 后，字段名、渠道来源、
> 排除词和地区范围以最新配置为准。所有收入均使用订单表中的“订单金额”标准字段；默认映射到“兑换美元”。

## 一、通用筛选

| 项目 | 当前口径 |
|---|---|
| 本周订单时间 | 订单生成时间位于本周开始日至本周结束日 |
| 上周 | 本周日期整体向前推7天 |
| MTD | 本月1日至本周结束日 |
| Web端订单 | 支付端口包含 `PC`、`移动` 或 `其他` |
| Web端注册 | 注册端口包含 `PC`、`移动` 或 `其他` |
| 新用户 | `注册转化周期 = 0`；字段和值可以在网站修改 |
| 订单去重 | 如果存在订单ID/订单id，按订单ID保留最后一条 |
| 注册去重 | 如果存在用户ID/用户id，按用户ID保留最后一条 |
| 订阅收入 | 末次来源类型归为 `Auto_Renewal` 的收入 |
| 除订阅收入 | 排除归因为 `Auto_Renewal` 的订单收入 |

## 二、末次归因渠道规则

渠道判断先看“合作渠道”，合作渠道优先级高于末次来源类型。

| 渠道 | 当前订单归因条件 |
|---|---|
| KOL | 合作渠道以 `KOL` 开头；或者合作渠道为空且末次来源类型属于 `KOL、Direct、Social_Organic` |
| Affiliate | 合作渠道以 `Affiliate` 开头；或者合作渠道为空且末次来源类型以 `Affiliate` 开头 |
| SEM | 合作渠道为空，且末次来源类型为 `SEM` |
| Auto_Renewal | 合作渠道为空，且末次来源类型为 `Auto_Renewal` |
| Unassigned | 合作渠道为空，且末次来源类型为 `Unassigned` |
| 教育认证 | 合作渠道为空，且末次来源类型为空 |
| SEO | 其他未匹配订单当前默认归入SEO；可在网站修改默认归类 |

注意：当前“SEM收入”使用的是 **合作渠道为空 + 末次来源类型=SEM**，不是订单表的
`渠道类型=SEM`。分地区SEM注册数仍使用注册表的 `渠道类型=SEM`。两个字段不要混淆。

## 三、全渠道周报核心指标

| 指标 | 计算公式及筛选逻辑 |
|---|---|
| WEB—新用户ROI | 统计周期内注册、注册转化周期=0的Web订单营收 ÷（表内总成本 + 自然来源成本总计） |
| WEB—新老综合ROI（除订阅） | 统计周期内所有Web订单的除订阅营收 ÷（表内总成本 + 自然来源成本总计） |
| WEB—新老综合ROI（含订阅） | 统计周期内所有Web订单的含订阅营收 ÷（表内总成本 + 自然来源成本总计） |
| WEB—英语地区新用户ROI | 英语地区末次归因新用户营收 ÷ 英语地区Google+Bing消耗 |
| WEB—繁中地区新用户ROI | 繁中地区末次归因新用户营收 ÷ 繁中地区Google+Bing消耗 |
| WEB—其他地区新用户ROI | 其他地区末次归因新用户营收 ÷ 其他地区Google+Bing消耗 |
| 新用户总收入 | SEM + KOL + Affiliate + SEO + Unassigned + 教育认证的新用户收入；不含Auto_Renewal |
| 新老用户总收入（除订阅） | 统计周期内全部Web订单收入，排除Auto_Renewal |
| 新老用户总收入（含订阅） | 统计周期内全部Web订单收入，包含Auto_Renewal |
| 自然来源新用户收入 | KOL + SEO + Affiliate + Unassigned + 教育认证的新用户收入 |
| 总成本 | 仅展示 SEM成本 + Affiliate分佣成本 + SEO外链成本；自然来源成本总计不展示在该行，只参与上方三项WEB ROI的分母 |
| Google 转 SEO 成本 | 每7天将 $350 从 Google/SEM 成本转入 SEO外链成本，即每天 $50；本周、上周、MTD 均按实际自然日数计算，一减一加，全渠道总成本不变 |
| 新用户客单价ARPPU | 新用户营收 ÷ 新用户订单量 |
| 新用户注册付费率 | 新用户订单量 ÷ 新增注册 |
| 注册率 | 新增注册 ÷ 流量 |
| 付费率（流量口径） | 新用户订单量 ÷ 流量 |

### 地区范围

| 地区 | 默认范围 |
|---|---|
| 北美 | 美国、加拿大 |
| 繁体中文 | 中国香港、中国澳门、中国台湾、香港、澳门、台湾、港澳台 |
| 英语地区 | 以网站“统计规则设置”中的英语地区国家清单为准 |
| 其他地区 | 总收入减去英语地区和繁中地区收入 |

## 四、SEM周报指标

SEM订单的基础筛选为：Web端、合作渠道为空、末次来源类型为SEM。

| 指标 | 计算公式及筛选逻辑 |
|---|---|
| SEM—SEM新用户ROI | SEM末次归因且注册转化周期=0的营收 ÷ SEM总消耗 |
| SEM—新老综合ROI（除订阅） | SEM末次归因新老用户除订阅营收 ÷ SEM总消耗 |
| SEM新用户总收入 | SEM基础订单中注册转化周期=0的订单金额之和 |
| SEM新老用户总收入（除订阅） | SEM基础订单的新老用户订单金额之和 |
| Google新用户营收 | SEM新用户订单中，末次来源为 `Google_SEM` 或为空的订单金额 |
| Bing新用户营收 | SEM新用户订单中，末次来源为 `Bing_Ads` 的订单金额 |
| 地区新用户营收 | SEM新用户订单按国家分组后的订单金额 |
| Google消耗 | Google消耗排除配置关键词后的费用，再按每天 $50 减去转入 SEO 的成本；默认排除 `KOL` 和 `generic` |
| SEM分地区—港澳台Google消耗 | 仅统计广告系列名称包含 `YM-CN-search-CV-tail-0907homepage` 或 `YM-CN-Pmax-CT-1020` 的港澳台费用；其他广告系列的港澳台Google费用不计入 |
| Bing消耗 | 排除 `Search total` 汇总行后的cost之和 |
| SEM总消耗 | Google消耗 + Bing消耗 |

SEM周报不输出 `SEM—新用户ROI（D7）`，也不再拆分PC端和H5端ROI。

## 五、SEM分地区周报

| 指标 | 计算公式及筛选逻辑 |
|---|---|
| 新增注册 | 注册表中该地区、Web端、渠道类型=SEM、广告来源不含FB的注册量 |
| 注册单价 | 该地区SEM消耗 ÷ 新增注册 |
| 客单价 | 该地区SEM新老用户营收 ÷ 新老用户付费量 |
| 新老用户注册付费率 | 该地区SEM新老用户付费量 ÷ 新增注册 |
| 新用户注册付费率 | 该地区SEM新用户订单量 ÷ 新增注册 |
| 新老用户营收 | 该地区SEM末次归因新老用户订单金额之和 |
| 新用户营收 | 该地区SEM末次归因且注册转化周期=0的订单金额之和 |
| 新老用户ROI（除订阅） | 该地区SEM新老用户除订阅营收 ÷ 该地区SEM消耗 |
| SEM新用户ROI | 该地区SEM新用户营收 ÷ 该地区SEM消耗 |
| 全渠道新用户ROI | 该地区全渠道、注册转化周期=0的营收 ÷ 该地区SEM消耗；仅美国、印度、港澳台展示 |

## 六、自然来源周报

| 指标 | 计算公式及筛选逻辑 |
|---|---|
| WEB自然量注册数 | Web端注册中，`末次来源类型 != SEM` 的注册量；空白及其他来源均计入 |
| APP自然量注册数 | 网站手动填写 |
| 注册总计 | WEB自然量注册数 + APP自然量注册数 |
| WEB自然来源新用户收入 | 末次归因属于 KOL、SEO、Affiliate、Unassigned、教育认证，且注册转化周期=0的Web订单收入 |
| WEB新老用户收入（除订阅） | 上述自然渠道的新老用户Web订单收入，排除Auto_Renewal |
| APP自然量收入 | 网站手动填写的APP自然量新用户收入 |
| 成本总计 | 达人合作费 + 投流费 |
| CPM | 成本总计 ÷ 当周曝光 × 1000 |
| 达人合作费:投流费 | 两项实际费用按合计10折算；目标固定为 `7:3` |
| 新用户ROI | （WEB自然来源新用户收入 + APP自然量收入）÷ 成本总计；成本为0时显示 `/` |

自然来源周报的本周、上周和MTD均使用以上口径；环比为本周相对上周的变化，完成率为MTD÷目标。

## 七、会员类型周报

会员类型周报复用订单数据，统计周期与网站选择的本周、上周和MTD一致。

| 指标 | 计算公式及筛选逻辑 |
|---|---|
| 基础订单 | 订单生成时间位于统计周期，支付端口包含PC、移动或其他 |
| 月卡-plus/pro | `VIP种类` 包含 `monthly`，会员等级分别包含 `plus` / `pro` |
| 年卡-plus/pro | `VIP种类` 包含 `yearly`，会员等级分别包含 `plus` / `pro` |
| 终身卡-plus/pro | `VIP种类` 包含 `lifetime`，会员等级分别包含 `plus` / `pro` |
| 订单量 | 对应会员类型的订单行数 |
| 付费额 | 对应会员类型的订单金额之和 |
| 占比 | 对应会员类型数值 ÷ 同期总订单量或总付费额 |
| 环比 | （本周数值－上周数值）÷ 上周数值；上周为0时显示 `-` |

会员类型表下方同时输出“全渠道分地区当月MTD订单量付费额占比”：

| 项目 | 计算公式及筛选逻辑 |
|---|---|
| MTD周期 | 网站结束日期所在月1日至结束日期 |
| 基础订单 | Web端订单，日期使用订单生成时间 |
| 所有地区总计 | MTD全部地区订单量及付费额 |
| 以下核心地区总计 | 除国家为空和`国家=其他`外，按MTD付费额降序排列的Top 13地区合计 |
| “其他”地区 | 仅统计订单表中`国家=其他`的订单 |
| Top 13明细 | 按MTD付费额从高到低排列；付费额相同时依次按订单量和地区名排序 |
| MTD占比 | 地区订单量或付费额 ÷ 所有地区对应总计 |

## 八、目标与完成率

| 项目 | 逻辑 |
|---|---|
| 目标 | 网站“月度目标设置”中对应月份和指标的目标值 |
| 完成率 | MTD ÷ 目标，保留整数百分比 |
| 时间进度 | 本月已经过天数 ÷ 本月总天数，保留整数百分比 |
| 百分比目标填写 | 目标100%填写 `100`；兼容旧配置中填写 `1` 的方式 |

## 九、修改规则的边界

网站可以修改字段映射、渠道来源、合作渠道前缀、Google排除词、新用户值和地区清单。
如果要新增指标、改变分子分母、关联新数据表或改变Excel结构，仍需要修改Python代码。
